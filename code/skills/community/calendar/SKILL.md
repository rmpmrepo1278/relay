# Calendar Prep Skill

**Purpose:** Provide meeting context and prep suggestions.

**Commands:**
- `/prep` - Show next meeting with attendees + agenda
- `/calendar` - Brief calendar overview

**Features:**
- Google Calendar OAuth (headless server compatible)
- Attendee list extraction
- Meeting description preview
- Web search for context (DuckDuckGo)
