# Meeting Assistant

**Purpose:** Proactive meeting support.

**When triggered:**
- 15 min before meeting: Send reminder with prep
- During meeting hours: Postpone non-critical tasks
- After meeting: Summarize and save notes

**Actions:**
- Pause backups during meetings
- Fetch relevant documents
- Set follow-up reminders
