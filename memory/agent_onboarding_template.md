# Agent Template — Adding New Specialists to the Hermes Stack

## Quick-Start Checklist (for Jenny / Chief of Staff)

When onboarding a new domain agent, execute these steps in order:

### 1. Define the Charter (playbook)
Create `~/.hermes/collaborator-memory/memory/<agent>.md`:
```markdown
# <Agent Name> — <One-line purpose>

## Mandate
<What this agent owns and is accountable for>

## Priorities
- <Bullet 1: measurable, checkable>
- <Bullet 2: measurable, checkable>

## Store
- Local store: `~/.hermes/agents/<agent>/store.json`
- Commands: <list of CLI commands>

## Schedule
- Runs at <cron> via <mechanism>
- Outputs to: agentbus + Telegram topic #<agent>
```

### 2. Build the Agent Script
Create `~/.hermes/scripts/<agent>_agent.py` following the pattern:

```python
#!/usr/bin/env python3
"""<agent>_agent.py — Specialist for <domain>."""

from __future__ import annotations
import json, os, sys
from datetime import datetime, timezone
from pathlib import Path

HERMES_HOME = Path.home() / ".hermes"
STATE_DIR = HERMES_HOME / "state"
LOG_DIR = HERMES_HOME / "logs"
# ... ensure dirs exist ...

def _log(msg): ...
def _load_state() -> dict: ...
def _save_state(state): ...
def _record_narrative(etype, content, metadata): ...
def _send_telegram(text, thread_id): ...
def _get_topic_id() -> int: ...

# Domain-specific check functions
def check_<domain>() -> dict: ...

# Self-heal / action functions
def heal_<issue>() -> dict: ...

def run_full_check() -> dict: ...

# Specialist handler for orchestrator
def <agent>_agent(task: dict) -> dict:
    action = task.get("type", task.get("action", "")).lower()
    # Route to check/heal/report/etc.
    return {"assignee": "<agent>", "task": task.get("content", ""), "status": "completed", ...}

if __name__ == "__main__":
    # CLI for manual testing
    ...
```

**Required interface for orchestrator:**
- Function named `<agent>_agent(task: dict) -> dict`
- Returns dict with: `assignee`, `task`, `status`, (optional) `confidence`, `health`, `heal_actions`

### 3. Register in Autonomous Confidence Calibration
Edit `~/.hermes/scripts/autonomous_self.py` → `_calibration_bucket()`:
```python
if "<agent>" in action:
    return "<agent>"
```

### 4. Register in Agent Orchestrator
Edit `~/.hermes/scripts/agent_orchestrator.py`:

```python
# In SPECIALISTS dict:
"<agent>": {
    "description": "<one-liner>",
    "triggers": ["keyword1", "keyword2", ...],
    "priority": <1-10>,
    "handler": "<agent>_agent",
},

# In domain_map (decompose_plan):
domain_map = {
    "<goal_domain>": "<agent>",
    ...
}

# In DISPATCH_TABLE:
DISPATCH_TABLE = {
    "<agent>": <agent>_agent,
    ...
}

# Add wrapper before DISPATCH_TABLE:
def <agent>_agent(task: dict) -> dict:
    try:
        from <agent>_agent import <agent>_agent as _impl
        return _impl(task)
    except Exception as e:
        return {"assignee": "<agent>", "task": task.get("content", ""), "status": "error", "error": str(e)}
```

### 5. Create Telegram Forum Topic
```bash
python3 ~/.hermes/agentbus/create_topics.py
# Or manually via Bot API createForumTopic
```
Add to `~/.hermes/agentbus/topic_map.json` (auto-generated by script).

### 6. Add to Jenny's Org Roster
Update `memory/jenny.md` table with:
| Agent | Area | Memory | Store |
| <Agent> | <Domain> | memory/<agent>.md | ~/.hermes/agents/<agent>/ |

### 7. Schedule (cron or scheduler)
Add to crontab or `hermes_scheduler.py`:
```bash
# Daily check at 04:45 (before Jenny brief)
45 4 * * * /usr/bin/python3 /home/rohit/.hermes/scripts/<agent>_agent.py check >> /home/rohit/.hermes/agents/logs/<agent>.log 2>&1
```

### 8. Test End-to-End
```bash
# Direct
python3 ~/.hermes/scripts/<agent>_agent.py check

# Via orchestrator
python3 -c "
from agent_orchestrator import dispatch_plan
print(dispatch_plan({'action':'check','content':'test','goal_domain':'<domain>','priority':5}))
"

# Verify Telegram delivery to #<agent> topic
```

### 9. Commit & Sync
```bash
cd ~/.hermes/collaborator-memory
git add memory/<agent>.md journal/relay-<agent>-onboarding-<date>.md
git commit -m "onboard: <agent> agent — <domain>"
git push
collaborator sync
```

## Pattern: Adding a "Career Coach" Agent (Example)

```bash
# 1. Playbook
cat > ~/.hermes/collaborator-memory/memory/career_coach.md <<'EOF'
# Career Coach — Career Development Agent
## Mandate
Track job applications, interview prep, skill gaps, networking.

- Surface relevant job postings daily
- Flag stale applications (>14d no response)
- Recommend skill-building based on market gaps
## Store
~/.hermes/agents/career_coach/store.json
## Schedule
Daily 06:00 via cron → #career_coach topic
EOF

# 3. Register in autonomous_self, agent_orchestrator
# 4. Create topic

# 7. Test
# 8. Commit
```

## Chief of Staff (Jenny) Onboarding Authority

Jenny owns the **onboarding pipeline** via these mechanisms:

1. **Charter approval** — New agent playbooks must be reviewed by Jenny (via `collaborator say coordination "onboard: <agent> — <charter>"`)
2. **Resource allocation** — Jenny assigns: topic ID, store path, cron slot, bus channel
3. **Quality gate** — Jenny runs the 9-step test checklist before declaring "active"
4. **Lifecycle** — Jenny can deprecate agents: `collaborator say coordination "deprecate: <agent> — reason"`

Jenny's daily brief includes: "New agents pending onboarding: <list>" and "Agents deprecated: <list>".

## Minimal New Agent (5 min scaffold)

For rapid prototyping, drop a single file:

```python
# ~/.hermes/scripts/quick_<agent>_agent.py
def quick_<agent>_agent(task):
    return {"assignee": "quick_<agent>", "status": "completed", "result": "ok"}
```

Then register in `agent_orchestrator.py` only (steps 3-4), test, then graduate to full template.
